# 🍞 My Sunny Bakery

A cozy bakery simulator with a cartoon PSX aesthetic. Bake, decorate, and run your dream bakery in a warm lo-fi world.

## ⚙️ Getting Started

### Prerequisites
- Unity **6.3 LTS**
- ["Arcade Vehicle Physics"](https://assetstore.unity.com/packages/tools/physics/arcade-vehicle-physics-193251) by Ash Dev — **paid asset, not included**, must be purchased and imported manually
